E-Ticaret Uygulaması

Bu proje, Node.js, Angular 18 ve MongoDB kullanarak geliştirilmiş bir e-ticaret uygulamasıdır. Kullanıcılar ürün ekleyebilir, silebilir, güncelleyebilir, sepete ürün ekleyebilir, sepet oluşturabilir ve siparişlerini yönetebilir.

🚀 Teknolojiler

Bu projede kullanılan temel teknolojiler:

Node.js - Backend için

Express.js - API geliştirme için

MongoDB - Veritabanı yönetimi için

Angular 18 - Frontend uygulaması için

📌 Özellikler

🔹 Ürün Yönetimi: Ürün ekleme, silme ve güncelleme işlemleri

🔹 Sepet İşlemleri: Ürünleri sepete ekleme, sepetten çıkarma ve sepeti görüntüleme

🔹 Sipariş Yönetimi: Kullanıcıların sipariş oluşturması ve sipariş geçmişini görüntüleme

🔹 Kullanıcı Yönetimi: Kullanıcı kayıt, giriş ve kimlik doğrulama

🔹 Admin Paneli: Ürün ve sipariş yönetimi
